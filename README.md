# 🌌 Problema Restrito de Três Corpos — Simulações em Python

Este repositório apresenta uma coleção de scripts e experimentos numéricos relacionados ao **Problema Restrito de Três Corpos (PR3C)**.  
O objetivo principal é realizar simulações utilizando:

- 🌞 **Sol**
- 🪐 **Netuno**
- 🪐 **Plutão**
- 🛰️ Um corpo de massa desprezível (caso restrito)

As simulações utilizam **dados reais das efemérides** — obtidos do **Jet Propulsion Laboratory (JPL)** — e exploram a dinâmica orbital desses corpos na escala de **milhões de anos**.

---

## 🧠 **Descrição do Problema**

O *Problema Restrito de Três Corpos* estuda o movimento de um corpo de massa muito pequena (como um asteroide, cometa ou satélite artificial) sob a influência gravitacional de dois corpos massivos cujas órbitas são conhecidas.

### 🔭 Neste repositório, exploramos:

- Movimento orbital usando dados reais do JPL Horizons  
- Simulações no caso **completo** (3 corpos massivos)
- Simulações no caso **restrito** (dois corpos massivos + 1 de massa desprezível)
- Análise da estabilidade orbital
- Cálculo de distâncias, ângulos, energia e integrais aproximadas do movimento

---

## 🚀 **Tecnologias Utilizadas**

- Python 3.10+
- NumPy
- SciPy (métodos de integração)
- Matplotlib
- Astropy
- JPL Horizons API (ou arquivos já exportados)

# PROBLEMA-RESTRITO-DE-TR-S-CORPOS-EM-PYTHON
Este repositório apresenta uma simulação do problema restrito de três corpos em pyhon: Neste trabalho, usaremos dados das efemérides de Plutão, Netuno e do Sol do Jet Propulsion Laborarory (JPL) para realizar simulações de 3 corpos e a simulações do caso restrito de três corpos na escala de milhões de anos.
